Plugins (MCP servers / connectors)

A plugin gives each bot on the team a set of tools. Tools are exposed with the mcp_{plugin}_ prefix to bots that subscribe to it; every non-read-only operation requires your approval.

Skills

A skill is a documented procedure. Every bot sees its one-line summary and loads the full text only when it applies, so installing many uses very little context.
