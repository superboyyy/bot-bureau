Plugins (MCP servers / connectors)

A plugin gives every bot on the team a set of tools. Tools are exposed with an mcp_{plugin}_ prefix to the bots that have it checked, and any non-read-only operation needs your approval first.

Available to install

Skills

A skill is a written-down procedure. Every bot sees each skill's one-line summary and loads the full text only when it applies, so installing many costs almost no context.

Plugin packages

Bot Bureau installs Claude / Codex plugin packages as they are. A package's MCP servers, skills and members are all taken in; anything not supported is listed after installing.
